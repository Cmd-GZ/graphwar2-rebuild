# 70 · 关卡生成器不止一种

## 1. 起因

找 AI 的"随机函数生成器"时，先列出 `next_u64`（`0x57f700`）的调用者：

```
0x4f1e50  关卡生成（随机散布，docs/55）
0x5625b0  ziggurat 正态采样（docs/55）
0x564d10 / 0x565a70 / 0x56f690   未看
0x578fc0 / 0x59f370             未看
0x5ea6dc / 0x5ea8a0 / 0x5ea9bc / 0x5eab32 / 0x5eaca6   ← 在"AI 区域"附近
```

最后那 5 个（0x5ea…）看起来像 AI，反编译后**不是**。

## 2. `FUN_005ea6dc`：圆盘式布局

> ⚠️ **运行时验证结果（见 `docs/72` §5）**：这个函数在真对局里**一次都没被调用**。
> 它能造出极坐标的障碍分布，但触发条件未知。
> 下面把它叫"关卡生成器"是**未经运行时证实的描述**，实际可能属于别的模式/功能。

```c
iVar7 = 0x40;                                  // 64 个
do {
    u1 = uniform();  u2 = uniform();
    r = u2 * 7.5;
    sincos((u1 + u1) * PI, &s, &c);            // 角度 = 2π·u1
    x = c * r;   y = s * r;                    // 圆盘内一点
    *(int *)(...) = param_3 + 10;              // 类型码 = 参数 + 10
    *(undefined4 *)(...) = 0xf;                // 半径/样式字段 = 0xf
    *(char *)(...) = 1;
} while (--iVar7);
iVar7 = 0x10;                                  // 再 16 个
do { 同样的流程，但 r = u2 * 3.0; 标志位 = 0; } while (--iVar7);
```

⇒ **圆盘式**：64 个障碍撒在半径 ≤7.5 的圆内，再加 16 个撒在半径 ≤3.0 的圆内。

与 `docs/55` 的"随机散布"（数量 `trunc(N(0,1)*7+15)`、半径 `max(N*1.6+2.6,0.8)`、
`x=(2r+25)(2u-1)`、`y=(2r+15)(2v-1)`）是**两套完全不同的生成器**。

## 3. 影响

`src/graphwar_level_generator.rs` 目前只实现了"随机散布"那一套（`docs/61` 逐位复现验证过）。
**其他关卡模式尚未实现**，包括：

- 圆盘式（本节）
- 其余未看的 `next_u64` 调用者（`0x564d10`、`0x565a70`、`0x56f690`、`0x578fc0`、`0x59f370`）
  里可能还有别的模式

⇒ README 里"关卡生成"那一行应理解为**"随机散布模式"已还原**，
不是在说所有模式都还原了。
