## 3. 回合出场顺序：有了验证手段（尚未验证）

同一局里同时抓随机流与事件，实测时序：

```
@draw 2   SoldierInfo{233,234}          ← 士兵创建
@draw 34  TurnInfo{230} + 其余 SoldierInfo
@draw 194 TurnInfo{234}                 ← 中间 160 次随机数被 AI/结算消耗
```

- 士兵创建与首个 `TurnInfo` 都发生在 `draw 34` 之前；
- 若出场顺序来自"开局洗牌"，洗牌必然落在 `draw 2..34` 这段；
- **4 个元素做 Fisher–Yates 只需 3 次随机数**，与这段的消耗量吻合，
  但**尚未把具体那 3 个值定位出来**，所以"开局随机打乱"仍属**推断**。

⇒ 这一块从"不可复现"变成了"**有明确验证手段**"，但本轮未完成验证。
