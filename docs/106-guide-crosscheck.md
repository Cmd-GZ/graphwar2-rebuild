这里把它的关键论断逐条与本仓库的 GW2 结论对账，避免"照着 GW1 写实现"。

| 指南的论断 | GW2 情况 | 依据 |

## 2. **GW2 不成立 / 不存在**（照抄会错）

| 指南的论断 | GW2 实际情况 | 依据 |
|---|---|---|
| 战场精确边界 `[-25,25) × [−1125/77, 1125/77)` | ❌ GW2 是 `\|x\|≤25`、**`\|y\|≤15`** 的硬编码 | `AGENTS.md`、`0x19fbc8`/`0x19fd40` |
| **聊天指令**（`-skip` 等） | ❌ **GW2 完全没有聊天指令**（用户确认）。检索：`strings` 里没有形如 `-xxx` 的命令串（只有 `-inft`/`/uqf` 这类噪声）；105 个反编译 `.gd` 里**没有任何命令解析**（无 `begins_with("-")` / `split(" ")` 之类） | 本轮检索 + 用户确认 |
| `y'` 与 `y''` 两种 ODE 模式 | ❌ GW2 **只有一阶**；且 `y'` 在 7 个求值点全传 0 | `AGENTS.md` dead feature |
| `sen(x)`、`tg(x)` 别名 | ❌ GW2 删了；`sen(x)` 会被静默解析成 `e·π·x` | `REPORT.md` §5.7 |
| `exp()` 是文本替换成 `e^` | ❌ GW2 有原生 `EXP` 算子（结果相同） | 同上 |
| `pi` token | 部分：GW2 预处理 `pi`/`π` → `n` | 同上 |

## 4. 用法

- 写实现时**先查本文档**：标 ❌ 的不要照抄；
- 指南里还有大量**公式与技巧**（台阶函数、尖刺函数、分段拟合、ODE 机制），
  那些是**玩法内容**不是引擎行为，与复原无关，但可用来构造测试用例
  （尤其是"陡峭/振荡/分段"的函数形状——`docs/89` 那个早停缺陷正是被陡峭函数触发的）。
