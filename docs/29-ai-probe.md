# 29 · AI 内部探针（定量刻画，规则未还原）

## 1. 入口分层（观测）

对一局高难度 Bot（`level:25`）挂 hook：

| 函数 | 次数 | 形态 |
|---|---|---|
| `0x51b440`（`function_evolutionator`） | **3**（≈每回合 1 次） | `(ctx, ?, 0xe8, 0xe9/0xea)` —— 后两个参数是 **player_id=232** 与 **soldier_id=233/234** |
| `0x51a750`（同模块） | **11475**（≈每回合 3800 次） | `xmm0 = 0.5`（采点步长），`rcx = 0xea` 固定 |
| `0x482c20` | 337 | `xmm0/xmm1` 是浮点（如 `-4.890, -4.524`），`rsi/rcx = 0x96 = 150` |
| `0x47a520`（`computer_player_manager`） | 0 | 本局未被调用 |
| `0x51d080` | 0 | 本局未被调用 |

⇒ AI 的形态是：**每回合选一次，内部做数千次"模拟射击"来打分**。
`0x51a750` 之前就从指针槽分析中确认会调用开火结算（`0x3c2bc0`），与此吻合。

## 2. 为什么还没还原规则

要复现 AI，需要三样东西，目前一个都没有：

1. **候选集的生成方式**（语法/变异算子）——只看到最终表达式；
2. **适应度函数**（打多少分、怎么累计）——只看到"调了几千次结算"，没有分值与输入的对应；
3. **随机数**——`(-46.06/(7.94+x))`、`cos((0.73*x))` 里的常数看起来是随机的，
   但生成它们的 RNG 状态拿不到，就无法复现同一局的同一结果。

抓到的成品函数（不同局）：

```
abs(x)  0.00  sin(x)                              ← 低难度
tan(sin((-0.12*x)))  abs((-3.49+x))               ← level:25
(-46.06/(7.94+x))  cos((0.73*x))                  ← level:25（另一局）
(-1.06*x)  (-23.81*x)  sin(x)                     ← 另一局
```

**没有任何一条能由"目标位置"直接算出**——我之前"斜率 = 指向目标"的假设，
在这些样本上不成立（-1.06 与四名士兵的任意两两斜率 -0.19/-0.34/0.57/-1.12/-1.42 都对不上）。

⇒ 这一行的状态应保持 🔶，并且"疑似瞄准"的说法要撤回。

## 3. 若要继续，最小可行路径

1. 在 `0x51a750` 上同时 hook 入参与**返回值**，收集 (候选, 得分) 对；
2. 用同一批候选做回归，看分值是否等于"命中人数/命中距离"之类的简单量；
3. 若能拟合，再反推候选生成；否则这条路要写成"不可达"。
