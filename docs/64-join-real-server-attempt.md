## 3. 已知的坑（都已排除）

- **`/tmp` 是每条命令独立的 tmpfs**：日志要写工作区，否则下一次命令就看不到；
- **`pkill -f Godot` 会连自己那条命令一起杀**：要按 PID 精确清理；
- **`ss -tln` 不带进程名**，匹配不到 Godot，必须 `-tlnp`。

## 4. 可能的原因（未验证）

1. 连接时刻不对：端口在游戏启动早期就存在，但服务器可能要到"创建房间"后才处理请求；
2. 首包可能不是 `NewConnectionRequest`：我们只按抓包里出现的第一条 JSON 推断，
   **尚未核对连接建立后最初的原始字节**（本轮想核实时，抓包里只有 D-Bus 流量，
   游戏没进到开房阶段）；
3. 监听 socket 可能不是对局协议（fd 8），而对局用的是另一个端口。
