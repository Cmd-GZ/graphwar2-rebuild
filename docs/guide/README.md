## 2. 证据标记（本手册的强制格式）

**每一条结论后面必须带下列四个标记之一。没有标记的句子不是结论，只是叙述。**

| 标记 | 含义 | 什么样的证据才够格 | 能不能写进"游戏就是这样" |
|---|---|---|---|
| `[逐位]` | 与真二进制**逐字节 / 逐位**对拍 | 能指到反汇编地址或逐字节对拍（如 `0x3c4452` 的 `cmp/je`、`0x417ef0` 的解析循环） | **能** |
| `[观测]` | 真实抓包 / 真机真帧 / 运行时统计 / 回放计数 | 能指到地址、字节、报文或样本数（如"45/45 份回放"、"frida 28 次光栅化里 8 次 `fill=0xFF`"） | **能** |
| `[推断]` | 有依据但不完全 | 必须同时写清**缺什么证据** | **不能**。要写就写"这是推断" |
| `[未知]` | 没有证据 | 只写"未知"和"缺什么" | **不能**（这正是攻略的空白区） |

三条附加纪律：

1. **`cargo test` / `selftest` 的通过不算证据。** 那是回归保护，不是复原证据
   （我们自己的断言只能证明"和实现一致"，不能证明"和原版一致"）。
   ⇒ 本手册**不引用任何测试条数**作为结论依据。
2. **数字必须可核对。** 本手册只写确定值：`0.01`、`±25/±15`、`20000` 点、`200` 弧长、
   `min_count`、`0.5`、`165` tick、`25` 秒、`3/25/50/100/250`……
   **不写**"大约""可能""大概是"。样本数一律写成"分子/分母"（如 `45/45`）。
3. **发现素材矛盾时，以更硬的证据为准，并登记到 [`../148`](../148-guide-manual.md) §3。**
   本手册已据此改写过若干条旧文档的说法（见 §5）。

## 4. 地址与编号约定（跨章统一）

| 约定 | 规则 |
|---|---|
| 地址 | 全部写 **ELF 虚地址（vaddr）** = `objdump` 打印的地址。**Ghidra/REA 地址 = vaddr + `0x100000`，只加一次** |
| 关卡编号 | 二进制内部是 **`level_0` … `level_20`（0 基）**；"第 N 关"= 1 基。**查存档、对表时用 `level_n`** |
| 队伍 | 队索引 `0` = 我方（Team1，`x < 0`）；索引 `1` = 敌方（Team2，`x > 0`）；靶子属于 Team2 |
| 坐标 | 棋盘坐标 `x ∈ [-25,25]`、`y ∈ [-15,15]`；像素 `px = 20x + 500`、`py = 20y + 300`（1000×600 画布） |
| 时间 | tick 是服务端计数器；**不是** 60 Hz 墙钟（`end_of_turn_tick` 与 60 Hz 对不上，`[未知]`） |
| 函数模式 | `NormalFunction`（`y=f(x)`）/ `DiffEqFunction`（`y'=f(x,y)`，RK4）；后者**不做修正 `c`** |

## 6. 怎么把一条 `[推断]` 升级成 `[观测]`

本手册里所有 `[推断]` 都对应一个**可判定的预测**（弹道停在哪、谁死、剩几个点、复盘哪一帧）。
升级路径只有一条：

1. 拿到**对照组**（例如"玩家函数注入"——这条路**目前没打通**，`docs/06` §15.3）；
2. 或者拿到**更多样本**（例如"部分命中"的回放：397 份里 **0 份**，所以目标复原规则只能停在推断）。

升级后请在改动的那一条上**同时改标记和补充"缺什么"**，并在 `148` §4 的"不完整章节"表里删掉对应行。
