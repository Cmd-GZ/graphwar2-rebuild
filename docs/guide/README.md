## 2. 证据标记（本手册的强制格式）

**每一条结论后面必须带下列四个标记之一。没有标记的句子不是结论，只是叙述。**

| 标记 | 含义 | 什么样的证据才够格 | 能不能写进"游戏就是这样" |
|---|---|---|---|
| `[逐位]` | 与真二进制**逐字节 / 逐位**对拍（**值级**） | 有**字节/数值级**的核对结果：`.rodata` 常量 8 字节直接读出来等于所写值、指令里的**立即数**逐字节读出来等于所写值、`.eh_frame` 边界字节、unicorn 直调真函数与本实现输出 `f64::to_bits()` 相同、报文/夹具逐字节相同。**⚠️ 只"能指到反汇编地址 / 读懂那几条指令的结构"不够格**，那属于 `[观测]`（2026-11-27 收紧口径；原写"能指到反汇编地址或逐字节对拍"把下限定宽了，见本节下面的**口径说明**） | **能** |
| `[观测]` | 真实抓包 / 真机真帧 / 运行时统计 / 回放计数 | 能指到地址、字节、报文或样本数（如"45/45 份回放"、"frida 28 次光栅化里 8 次 `fill=0xFF`"） | **能** |
| `[推断]` | 有依据但不完全 | 必须同时写清**缺什么证据** | **不能**。要写就写"这是推断" |
| `[未知]` | 没有证据 | 只写"未知"和"缺什么" | **不能**（这正是攻略的空白区） |

**⚠️ 口径说明（2026-11-27 收紧；T61 定定义，T68 回改历史条目）**：上表的 `[逐位]` 下限定在
**AGENTS.md §0.3 的原义**——"与真二进制逐字节/逐位对拍"。本手册早期版本的标记表把
"能指到反汇编地址"也并进了 `[逐位]`，所以 2026-11-27 之前写下的 `[逐位]` 里有相当一部分
只做到了"指到地址 + 逐条读懂语义"（那是 `[观测]` 的强度）。

- **T61**（2026-11-27）只收紧**定义**，历史条目没动；
- **T68**（同日）把历史条目**逐条重新判档并回改**：9 章正文共 **293 条** `[逐位]` →
  **T-真逐位 20 / O-应降为观测 210 / I-应降为推断 51 / M-元引用 12**；
  实际回改 **261 处**（`O`→`[观测]` 210 处；`I`→`[推断]` 51 处并逐处写明缺什么），
  另给 4 行补了原本缺的出处（3 个整段无指针的段落里）。台账：`fixtures/guide_marker_triage.tsv`（一行一条，带判定规则与升级路径），
  判据与复算命令在 `tools/guide_marker_triage.py` 文件头（`--self-test` 是 6 条正对照 + 5 条负对照）。

⇒ **现在本手册里出现的 `[逐位]` 一律是真·逐位（值级对拍）**，不再需要"分档读法"。

**判分界的三条例子**（都是本手册真实条目，T68 判档的依据）：

* "常量 `1e6` 在 `0x19fb30`" ⇒ `[逐位]`（**且写出了字节读数** `0x412e848000000000`；只写地址不写字节读数的是 `[观测]`）；
* "`0x46f310` 里发 `TeamInfo{Team2}`" ⇒ `[观测]`（只有地址 + 读懂它发什么事件，没有值级结果）；
* "冻结语料 4323 条可判队伍的 `PosInfo` 里 2 条反例" ⇒ `[观测]`（样本统计，不是与二进制对拍）。

**T68 的一条边界判定（比上表略严，写在这里避免下次争议）**：**引了立即数、但结论是行为/结构**的条目判
`[观测]`。例："AI 每代开头查一次 `elapsed > 25 s`，`0x51b7cf cmp $0x19`" —— `0x19` 那个值本身可字节复核，
但"每代开头查一次"是控制流，值只是论据之一。这类混合条**按弱的判**（全书 7 处）；
它们也是最容易升回 `[逐位]` 的：把一条拆成"值"和"行为"两条，值那条立刻够格。

T61/T68 改动的条目都在原文里写清了是哪一条指令 / 哪一份回放 / 哪个 `src` 文件:行，
并且**按收紧后的口径**标。

三条附加纪律：

1. **`cargo test` / `selftest` 的通过不算证据。** 那是回归保护，不是复原证据
   （我们自己的断言只能证明"和实现一致"，不能证明"和原版一致"）。
   ⇒ 本手册**不引用任何测试条数**作为结论依据。
2. **数字必须可核对。** 本手册只写确定值：`0.01`、`±25/±15`、`20000` 点、`200` 弧长、
   `min_count`、`0.5`、`165` tick、`25` 秒、`3/25/50/100/250`……
   **不写**"大约""可能""大概是"。样本数一律写成"分子/分母"（如 `45/45`）。
3. **发现素材矛盾时，以更硬的证据为准，并登记到 [`21`](../21-guide-manual.md) §3。**
   本手册已据此改写过若干条旧文档的说法（见 §5）。

## 4. 地址与编号约定（跨章统一）

| 约定 | 规则 |
|---|---|
| 地址 | 全部写 **ELF 虚地址（vaddr）** = `objdump` 打印的地址。**Ghidra/REA 地址 = vaddr + `0x100000`，只加一次** |
| 关卡编号 | 二进制内部是 **`level_0` … `level_20`（0 基）**；"第 N 关"= 1 基。**查存档、对表时用 `level_n`** |
| 队伍 | 队索引 `0` = 我方（Team1，**常规开局后** `x < 0`）；索引 `1` = 敌方（Team2，`x > 0`）；靶子属于 Team2。⚠️ **不是"永远"**：冻结语料 4323 条可判队伍的 `PosInfo` 里 2 条反例（开局切换瞬间），见 [`01 §1`](01-对局规则.md) |
| 坐标 | 棋盘坐标 `x ∈ [-25,25]`、`y ∈ [-15,15]`；像素 `px = 20x + 500`、`py = 20y + 300`（1000×600 画布） |
| 时间 | **两种时钟别混**：`tick` = 服务端整数计数器，**正好 60 tick/秒**（1 tick = 16 666 666 ns）；**AI 的 25 s 预算是墙钟**，与 tick 没有换算关系。详见 [`06`](06-时钟与回合推进.md) §1/§2 |
| 函数模式 | `NormalFunction`（`y=f(x)`）/ `DiffEqFunction`（`y'=f(x,y)`，RK4）；后者**不做修正 `c`** |

## 6. 怎么把一条 `[推断]` 升级成 `[观测]`

本手册里所有 `[推断]` 都对应一个**可判定的预测**（弹道停在哪、谁死、剩几个点、复盘哪一帧）。
升级路径只有一条：

1. 拿到**对照组**（例如"玩家函数注入"——这条路**目前没打通**，`docs/06` §15.3）；
2. 或者拿到**针对性样本**：`[推断]` 常常只说明"**我们的语料里没有这种情况**"，不等于"游戏里没有"。
   目标复原规则就是这么升级的：冻结语料 397 份里"部分命中" **0 份**，
   但用户**针对性打了两把**就同时拿到正例与反例（`docs/06` §34b）。
   ⇒ 先问"这个局面能不能**自己制造出来**"，再谈"样本不足"。

升级后请在改动的那一条上**同时改标记和补充"缺什么"**，并在 `21` §4 的"不完整章节"表里删掉对应行。
