# 89 · 实况步长是 **0.01**，不是 0.5（此前所有对比都用了错参数）

## 1. 怎么发现的

追查 `docs/86` §9.1 的"采样器提前中止"时，发现该缺陷**只在 step=0.01 下出现**。
于是反问：实况到底用哪个步长？同一批 21 发，用三个步长各跑一遍比停点：

| step | 中位 \\|Δx\\| | \\|<0.05\\| | 最大 |
|---|---|---|---|
| 0.5 | 0.130 | 6/21 | 0.5 |
| 0.1 | 0.036 | 15/21 | 0.1 |
| **0.01** | **0.000** | **20/21** | 2.2 |

**step=0.01 时中位差为 0.000**（20/21 在 0.05 内），唯一离群值是 2.2——
正是 §9.1 那个提前中止的样本。

⇒ **实况步长 = 0.01**，与 `AGENTS.md` 记的 `0x3f847ae147ae147b` 一致。

## 2. 这意味着什么

| 影响 | 说明 |
|---|---|
| 此前 `docs/83`/`84` 的"21 发差 <0.5、击杀数一致" | **参数用错**（0.5），结论虽未被推翻，但**证据强度要重算** |
| 采样器早停缺陷 | **真实存在且影响线上**（step=0.01 下约 1/21 ≈ 5%，与子 agent 报的 4/93 相当） |
| "0.5 是实况"的说法 | **错误**，本文件更正 |

## 3. 为什么 0.5 也能"看起来对"

停点是连续曲线的第一个碰撞点，采样步长只影响**离散化误差**：
0.5 步长下停点误差约 ±0.25，正好对应实测中位 0.13。
所以错步长不会让结果离谱，只会让它**不够精确**——这也是它能骗过我之前几轮的原因。
