# §2 逐条取证方法（写死，不许事后换）
# ============================================================================
# 通用四步：
#   (1) `tools/addr_probe.py fde <linux>` 取 FDE 真范围（不信 `.symtab` st_size，T101 §149）
#   (2) `tools/addr_probe.py dis <linux>` 读控制流/常量/调用点；关键指令连地址写进落码注释
#   (3) `tools/addr_probe.py callers <linux>` + `locs <linux>` 补调用者与 `panic::Location`
#   (4) 语义**必须**由 (2) 的指令决定；读不出的一律标「未解」，不许编
#
# §2.1 跨构建配对（android ↔ linux）——**不靠名字投票，靠三条独立链**
#   a. **相邻性/链接序**：同一 crate 内两构建的模块内函数顺序一致 ⇒ 若 android 上 A 紧接 B
#      （addr+span == next addr），linux 上同模块已锚定的 B' 之前恰好有 A'，且**两条的
#      `FDE 跨度比例` 同量级**，则 A↔A'（**观测**）。
#      本批实测：S1 后面紧接 `calculate_shot_results`（android 0x3b5770 ↔ linux 0x3c2bc0，
#      T81 已用它做隔离对拍）；S2 后面紧接 S3（android/linux 两侧都严丝合缝）。
#   b. **值级对拍**（本文件 §3）：S1/S2/S3 有可隔离执行的入口（ABI 已知：见 §3），
#      真机器码跑出来的输出与我方实现**逐位/逐字符串**相同 ⇒ 地址取错则不可能全同。
#   c. `panic::Location`（仅当函数体内有 Location 时）：本批 11 条 **全部 gameLOC=0**（T105 观测），
#      所以这条对它们**用不上** —— 这正是它们进不了 527 分母的原因（不是它们不存在）。

#   输入集 V1（≥16 组）：token 流取 {常量 0, x, x+1, x^3, sin(x), exp(x)+ln(x), -x, 空 token 流}
#      × x0 ∈ {0.0, -0.0, 5.0, -24.5, 1e308, NaN} × (flip, mode) ∈ {(0,0),(1,0),(0,1),(1,1)}
#      中固定 20 组；**ODE（mode=1）必须覆盖**（RK4 一步），**空 token 流 + ODE** 也要覆盖
#      （ours 里有"空 = 导数 0"的分支）。判据：点数相同 + **每个点 16 字节逐位相同**。

#      （ABI：x86 `rdi=sret(64B)`, `rsi=text_ptr`, `rdx=len`, `rcx=&Point{x,y}`, `r8b=flip`；
#       沿用 `tools/crossarch_emu.py::X86.textpt` 的既有口径）
#   输入集 V2（≥24 组）：text ∈ {"", "0", "x", "x/2", "x^3", "x ^ 3", "X^3", "x^3   ", "  x^3",
#      "sin x", "sin(x)", "tan(x)", "sqrt(x)", "exp(x)+ln(x)", "abs((abs((-0.57+x))+-4.85))",
#      "1/0", "sqrt(-1)", "2+3", "x/100000"} × (x,y,flip) 覆盖 {0,-0.0,1,-1,2.5,-24.5,24.5,
#      ±inf, NaN, 1e308, 1ulp 邻域}；y ≠ 0 至少 6 组（把 c=y0−f(±x0) 两个符号都钉住）。
#      flip 还测 `flag=0x100`（低字节 0 ⇒ 真二进制不反向 ⇒ 证明第 4 参是 **bool 而非 mode**）。
