## 2. 规则 R1–R6（预注册）

### R1 删除顺序 = 单删边际（升序）

按 71 号调参半的单删边际，从"删掉最不疼"到"删掉最疼"排队：

```
size (+2) → consts (−1) → caller (−1) → scal (−8) → gram (−99)
```

平手（`consts` 与 `caller` 都是 −1）时**权重小的先删**（`consts .25` 先于 `caller .5`）。
**权重一律冻结在 REF5 的取值上**，本规则只删列、不调权 —— 这样"列数"与"调参"是两个变量。

### R2 阶梯（嵌套，5 列 → 1 列）

| 级别 | 特征集（权重照抄 REF5） | 列数 |
|---|---|---|
| **L0** | `size.25 gram2 consts.25 caller.5 scal.5` | 5 |
| **L1** | L0 − `size` | 4 |
| **L2** | L1 − `consts` | **3**（= 任务书 ④ 的三列问法） |
| **L3** | L2 − `caller` | 2 |
| **L4** | L3 − `scal` | 1 |

### R3 停止条件（预注册，只用调参半）

从 L0 往下走，**停在第一个调参半 top-1 严格低于 L0（444/494）的级别**；
那个级别的前一级就是预注册选中的"瘦身表"。若某级与 L0 打平（≥444）则继续往下删。
**留出半不参与这一步** —— 留出半上每一级都照样报（曲线，不挑格）。

### R4 三列再调权（预注册网格，调参半选）

在 L2 的 3 列上跑固定网格，**只在调参半上选**：

```
G3 = gram ∈ {1, 2, 3} × scal ∈ {0.25, 0.5, 0.75, 1.0} × caller ∈ {0.25, 0.5, 1.0}   → 36 组
G2 = gram ∈ {1, 2, 3} × scal ∈ {0.25, 0.5, 0.75, 1.0}（caller = 0）                → 12 组
G1 = gram ∈ {1, 2, 3}（其余 0）                                                     →  3 组
```

选中规则：调参半 top-1 最高；并列桶 = ≥ 最高 − 1 个样本；桶内取**非 0 特征最少**者，
再并列取**权重和最小**者，再并列取 `ORDER` 序最小者（全部先定）。
留出半：报选中组 + 并列桶的 min/max/最高（**并列桶最高**这一格就是"口径双报"里的第二格）。

### R5 24 列等权口径能砍到几列（审计，不是默认配置）

起点 `S0 = 24 列等权 0.5`（`strs` 权重恒 0 ⇒ 实际 23 列参与），**逐轮删一列**：

* 每轮在调参半上算"删掉每一列"的 top-1，取最高者；**Δ ≥ 0 就接受删除**（并列时取 `ORDER` 序小的），
  Δ < 0（所有单删都掉点）则停止；
* 权重全程保持 0.5（不调权）—— 这一条只回答"这些列在等权组合里可不可以被删掉"，
  **不回答**"它们对默认配置有没有边际"（后者由 71 号的 LOO 表回答）。

产出：**24 → M 列**的阶梯曲线（两半都报）。

### R6 两侧覆盖率（防"单侧有"）

对 24 个特征逐个在**真配对**上量四格覆盖率（v2 留出半 481 行）：
两侧都有值 / 只有 Linux 侧 / 只有 Windows 侧 / 两侧都没有。
被删的列必须逐个报这四格 —— 若某列是"单侧有"，那正是它不该被当成证据的原因
（72/75 号的教训）；保留的列也报一遍，确认删列**没有**把某一列变成单侧。

## 3. 预注册的判据（先定，后看数）

1. **④ 三列行不行**：L2 的留出半 top-1 与 L0 **相等**（424/481）或更好 ⇒ "3 列够"；
   掉 1 个样本算打平（±2.8 点的 CI，1 个样本 = 0.21 点，**必须连配对检验一起说**）；
   掉 ≥2 个样本 ⇒ "3 列不行，掉 N 个，最小是 L1 的 4 列"。
2. **瘦身表 = R3 的选中级**；若 R3 的选中级与 L2 不同，**以 R3 为准**（R4 只作补充）。
3. **不许**用留出半回头改规则；若 R3 选中的级别在留出半上掉点，照写"删到 X 列开始掉、掉多少"。
