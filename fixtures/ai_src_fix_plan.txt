# [3] 取片段是**裸切片** `[r1, r1+r2)`，不按 arity 走子树、不 `r2.max(1)`
#   EV 0x4ee4ee / 0x4ee4f6 两次 `call 0x502b20`（= `next_u64`，**每次吃 2 个字**：
#      0x502b54 `mov rbx,[r15+rax*4+0x10]` 8 字节读 + 0x502b49 `rcx=rax+2` 游标 +2）
#      第一次：0x4ee50a `div r15` → r1 = u64 % N（N = 父代 len）
#      第二次：0x4ee521 `rsi = N - r1`；0x4ee533 `div rsi` → rdx = u64 % (N-r1)；0x4ee543 `rdx += rdi` → cut2 = r1 + r2

#   CHANGE: `r2 = u64 % (N-r1)`；`end = r1 + r2`；`out = parent[r1..end].to_vec()`；不按 arity 走子树。
