## 1. 判据（跑完不许改）

### 沿用 T32 的四档
* **E1** 字段数：`.data.rel.ro` 的 `&'static str` 槽 `(ptr,len)` ⇒ `read(addend,len)` 整体匹配
  `struct <Name> with N element(s)`。**逐位**。
* **E2** 字段名 + 声明顺序：`Serialize` 的 `lea rsi,[rip+名] ; mov edx,LEN ; … ; call <单态>` 序列，
  代码顺序 = 声明顺序 = 线上键序。**逐位**（`LEN` 自校验）。
* **E3** 字段偏移：同一函数里 `lea rcx,[self+k]` / `mov rcx,self` 给出**值指针偏移**。**观测**。
* **E4** 结构体尺寸：只给**下界**（被调方写回的最后一个偏移 + 宽度）。**推断**。

### 本轮新增（工具已实现，命令见文件头）
* **E5 单态 → 类型类**：`serialize_field<T>` 的单态地址按 T 唯一化（T32 已用它判「枚举/串/整数」）。
  本轮把「单态体指纹」写死成可复算判据：
  - 跳表形态（`movsxd rX,dword ptr [rY+rX*4]` + `add rX,rY` + `jmp rX`）⇒ **枚举**，
    case 下标 = 判别值（跳表顺序 = 声明顺序 = 判别值顺序）；
  - `cmp byte ptr [reg], N` + `cmovne` / `cmp byte,1 + jne L` ⇒ **2 变体枚举**；
  - itoa 的 u32 阈值 `0x2710` 与 `0x5f5e0ff` 且**无** `js/jl/neg` ⇒ **无符号 32 位**；
  - 只有 `write_str`/缓冲扩容两个汇点、无数值格式化 ⇒ **串**。
* **E6 变体名字面量**：枚举 `Serialize` 的每个 case 一条 `lea r?,[rip+变体名]` + `mov r32,LEN`
  （LEN 自校验：`read(ptr,LEN)` 必须是 `[A-Za-z][A-Za-z0-9]*`）。**逐位**。
  ⚠️ 两个坑（已写进工具注释）：①跳表的 `case` 顺序**不等于**代码地址顺序，必须按跳表项下标读；
  ②`cmp byte ptr [rdi + 8], 1` 是 serde map 的「首个字段」状态字节，**不是**判别式，带位移的 `cmp` 必须排除。
* **E7 非 serde 结构体窗口**：在一个**可归属函数**里找「同一基址寄存器上 ≥4 个不同固定偏移」的
  读写窗口（`mov/movsd/movss/movaps/movdqu/movups`，基址 ∉ {rsp,rbp,rip}，位移 ∈ [0,0x800)），
  窗口下界 = `max(位移 + 访问宽度)`。**推断**（只给下界；上界要调用方夹逼，本轮不做）。

### 判定规则（与 T32 完全一致，跑完不许改）
* **match**：E1 的 N == 我方字段数，**且** E2 的名字集合与顺序与我方一致（Group B 用
  E6 的变体名+判别值替换 E2，即「变体集合 + 判别值」全等才算 match）；Group C 里
  「只有 E7 下界」的行**一律 unknown**（T32 原话：「只登记，不猜」）。
* **mismatch**：E1/E2（或 E6）任一不一致。
* **unknown**：拿不到 E1/E2/E6 之一，或只有 E4/E7 的下限。
* 只修「mismatch 且证据一边倒」的；模棱两可只登记。
