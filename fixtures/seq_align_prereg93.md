## 3. 算法（保序全局对齐；带状 **max-sum** DP + 强制搭档的分数损失做置信）

```
匹配质量  q(i,j) = (w_size·S + w_ctx·C) / (w_size + w_ctx[若两侧都有 C])
  S = exp(-(ln(sA/sB) / size_sigma)²)，ln(sA/sB) 超出 [ln0.40, ln2.20] ⇒ S = 0（硬闸）
  C = clip(1 − mean_{t∈±1..±k}|ln sA[i+t] − ln sB[j+t]| / ctx_beta, 0, 1)，可用邻域 < ctx_min 则不计
跳步      每跳过一个 A 元素或一个 B 元素各罚 gap（允许内联 / ICF / 单侧单态化 ⇒ 两侧都可以"多出来的"）
目标      **max-sum**：max Σ q(匹配) − gap·(跳过数)，约束是保序
前向      F[i][j] = max(F[i-1][j-1]+q, F[i-1][j]−gap, F[i][j-1]−gap)；Z = F[na-1][nb-1]
后向      B[i][j] = max(q(i+1,j+1)+B[i+1][j+1], −gap+B[i+1][j], −gap+B[i][j+1])
强制分    S(i,j) = q(i,j) + F[i-1][j-1] + B[i][j]      （**强制**这条匹配时整条对齐的最优分）
决策      **回溯 Viterbi 路径**（保证 1:1 + 保序），路径上的 (i,j) 才算"对齐"；其余记"跳过"
置信      best1/best2 = S(i,·) 的最大/次大；**margin = best1 − best2**（与 q 同量纲的分数损失）
          档 A/B/C 由 (q, margin) 的**预注册**阈值定（q < q_min 一律"无对齐"）
带状      |j − round(i·NB/NA)| ≤ band（band 是唯一控制规模的旋钮：格数 = NA·(2band+1)）
```

**为什么是 max-sum 而不是 sum-product（这是 commit 之前就实测/推算过、并写进预注册的取舍）**：
线性跳步罚分下"跳 A / 跳 B"的**交错顺序**是多条不同路径，路径数按 C(n,k) 增长。13,263×12,609 上
"全跳过"那一族的总权重 ≈ `exp(−0.15·25,872) · C(25,872,13,263) ≈ e^{1.4e4}` 倍于任何含匹配的对齐
⇒ sum-product 的"匹配后验"会被跳步交错**完全淹没**（实测：band=64 那一版在 12,736 行里
**10,219 行落到最低档**、行内归一后的最大后验只有 **0.2–0.4** 量级、`p_match` 低到 0.17），
它测的不是"这个搭档对不对"。所以改成 max-sum，置信度用
**"强制换搭档的分数损失"**：它跟 q 同量纲，可解释，且不受路径计数影响。
（sum-product 版本的实现也做了穷举对拍，`max|ΔZ| = 3.55e-15`；被换掉是**建模理由**，不是数值问题。）

## 3b. 实现正确性（先行正对照，不是"跑出来像"）

`python3 tools/seq_align.py brute --n 150`：在 150 组随机小序列（2×2 … 4×5）上把带状 DP 与
**穷举所有保序对齐**逐格对拍，三条都比：

| 检查 | 结果 |
|---|---|
| 最优分 `Z` vs 穷举最大 | `max|ΔZ| = 4.44e-16`，不符 **0/150** |
| **强制匹配分** `S(i,j)` vs 穷举（每条路径的最优分再按"含 (i,j)"过滤取最大） | `max|Δ| = 4.44e-16`，不符 **0 格** |
| 回溯出的 Viterbi 路径：保序 + 1:1 + 分数 == 穷举最优 | 不符 **0/150** |

⇒ 下面报的每一个 margin 都是这个 DP 的输出。（这一条在预注册 commit 里就跑过；纯**实现**自检，不涉及真值。）

## 6. 已知的口径风险（先写下来，免得事后当发现）

1. **x86 是 2026-08-28、arm64 是 2.0.60**：跨版本 ⇒ 函数顺序可能被版本差异打乱一部分。
   `tools/sym_match.py` 已量过「269 对真值里 79% 的相邻对索引差完全相同」，这是本轮的**外部先验**，不是本轮结论。
2. **两侧编译器不同**（LLVM vs 未知版本）：内联决策不同 ⇒ 两侧都有"多出来的函数"，
   这就是 `gap` 与"无对齐"档存在的理由，也是本轴**结构性**的准确率上限。
3. **体量比不是常量**：同为 1:1 的真配对，体量比也有分布（`docs/02` §46.3③ 同 ISA 是 0.86/0.99/1.07）；
   跨 ISA 会更宽 ⇒ `size_sigma=0.30` 可能偏紧，网格里 `gap` 的扫描就是对它的鲁棒性检查。
4. **后验不是校准概率**：它是"在这套分数下的 Boltzmann 权重占比"，只能当**排序/置信信号**用。
   档位精度在真值上会被实测，**不会**假设它等于 q1。
