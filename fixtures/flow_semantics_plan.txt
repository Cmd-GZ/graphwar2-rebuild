## 1. 名词与轴（这四个判据全都要用，先钉死）

* **tick 轴**：60 Hz，`NANOS_PER_TICK = 16_666_666`（`src/graphwar_tick_handler.rs`），
  由 `GraphwarTickHandler::tick`（x86 **`0x519840`**）推进：`accum += 16_666_666 ns; tick += 1`。
* **`GraphwarTickHandler.current_tick`**：载荷 **`+0x40`**（`0x4b6317 mov 0x58(%rbp),%ebx`，
  `rbp` = RefCell 借用守卫 ⇒ 载荷在 `rbp+0x18` ⇒ `rbp+0x58` = 载荷 `+0x40`）。
* **`end_of_turn_tick`**：服务端 `EndOfTurnInfo` 的字段（线上 i64，`docs/07` §3.3），
  语义 = 这一回合的截止时刻（`docs/14` §3.2 回归：`end ≈ 回合开始 tick + 时长`）。
* **"本回合已过 tick"**：我方 `TurnClock` 自己积出来的量（`advance(delta)` 折 tick）。

## 2. ① `RoundCollection::expired` / `should_resolve(now_tick)`

### P1-1 判据源（预注册：这就是"有人不交怎么办"的指令级出处）

`Match::handle_tick`（x86 **`0x470840`**，我方 `src/game.rs` 的 `handle_tick`）第二段
（`docs/14` §11.3 已记这一段，本轮**逐条复核**）：

```text
0x470989  cmp  byte ptr [rbx+0x120], 2   ; ① 状态 == WaitingForFunctions(2)
0x470990  jne  0x4709fb                  ;    否则跳走
...
0x4709ce  call 0x462ec0                  ; TurnManager::get_end_of_turn_tick → Option<u32>
0x4709d7  cmp  eax, 1                    ; ② Option 判别 == 1(Some)
0x4709da  jne  0x4709f1                  ;    None ⇒ 不结算（TimerInf 档）
0x4709dc  cmp  ebp, edx                  ; ③ ebp = now_tick, edx = end_of_turn_tick（u32）
0x4709de  jb   0x4709f1                  ;    now < end ⇒ 跳过；**continue ⇔ now >= end**
0x4709e0  cmp  byte ptr [rbx+0x11c], 0   ; ④ "有人在等"(+0x11c) != 0
0x4709e7  je   0x4709f1
0x4709e9  mov  rdi, rbx
0x4709ec  call 0x470eb0                  ; ⑤ fire_functions：把**已提交的**打出去 = 按现有内容结算
```

### P1-2 边界（预注册：`>=` 不是 `>`）

`jb`（unsigned below）在 `now < end` 时跳过 ⇒ **触发条件是 `now_tick >= end_of_turn_tick`**。
`RoundCollection::expired` 现行实现 `matches!(self.deadline, Some(d) if now_tick >= d)` **边界已经一致**
⇒ 本轮**不改边界**，只接 deadline。验收断言必须钉住 `now == deadline` ⇒ true、`now == deadline-1` ⇒ false。

### P1-3 轴的选择（预注册）

原版 `now_tick` 与 `end_of_turn_tick` 在**同一条轴**上（同一台 `GraphwarTickHandler` 的 60 Hz 计数）。
我方本地局没有服务端 `EndOfTurnInfo`（本地 `Match` 在 Rust 里），`GwTurnClock` 只积"本回合已过 tick"
⇒ 我方接线用**同轴等价的差值形式**：`deadline = TurnClock::turn_duration_ticks()`，
`now_tick = 本回合已过 tick`（`TurnClock::advance` 的累加值）。两者同减一个常量 ⇒ 比较结果逐位等价。
**在线局不用这条**（在线局的截止由服务端 `EndOfTurnInfo` 给，见 §5 的 `P4-*`）。

### P1-5 单测与"不死锁"的证明方式（预注册）

1. `expired` 只在 `Some(d)` 且 `now >= d` 时为真（`None` 恒假）；

## 5. ④ 联机倒计时的 tick 轴

### P4-1 判据源（预注册：原版倒计时用哪两个数相减）

宿主 `0x3dcbb0`（`locs`：`graphwar_game_client.rs`×25 + `graphwar_play_screen_control.rs`×18，
是播放屏那台 `process` 大函数）。倒计时那一段：

```text
0x3dccd6  mov  ebx, dword ptr [r15+0x58]   ; ebx = now_tick（u32）
                                           ;   r15 = RefCell 借用守卫（+0x10 借用计数、载荷在 +0x18）
                                           ;   ⇒ [r15+0x58] = 载荷 +0x40 = GraphwarTickHandler.current_tick
                                           ;   与 0x4b6317（平面 draw）读的是**同一格**
0x3dcce4  call 0x46b740                    ; borrow 回合管理器
0x3dcd2c  call 0x462ec0                    ; TurnManager::get_end_of_turn_tick → Option<u32>
0x3dcd35  test al, 1
0x3dcd3f  je   0x3dced5                    ; None（TimerInf）⇒ 别的分支（标签空白）
0x3dcd47  sub  edx, ebx                    ; edx = end − now（u32 模 2^32 减法）
0x3dcd49  cmovb edx, eax(=0)               ; **借位 ⇒ 0**（= saturating_sub，绝不会出负数）
0x3dcd4c  imul rax, rdx ; shr rax, 0x25    ; rax = (end−now) / 60        = 剩余整秒（截断）
0x3dcd59  imul rcx, rdx ; shr rcx, 0x2b    ; rcx = (end−now) / 3600      = 剩余整分
0x3dcd6d  imul rcx, rax, 0x8888889 ; shr rcx, 0x21 ; imul ecx,0x3c ; sub eax,ecx
                                           ; eax = 秒数 − 分*60 = 剩余秒
0x3dcdc9  mov  byte ptr [rax+rsi], 0x3a    ; 拼 ':' ⇒ 格式 **MM:SS**
```

三个魔术数：`/60` = `0x88888889 >> 0x25`、`/3600` = `0x91a2b3c5 >> 0x2b`、再 `/60` = `0x8888889 >> 0x21`。

### P4-2 结论（预注册的判定）

`end_of_turn_tick` 的轴 = **与 `GraphwarTickHandler.current_tick` 同一根 60 Hz tick 轴**
（两者**直接相减**，中间没有任何"回合开始 tick"的换算）⇒ **绝对轴**，不是"本回合已过 tick"。
推算：`剩余秒 = saturating_sub(end_of_turn_tick, now_tick) / 60`（整数除，截断）⇒ `MM:SS`。
（与 `docs/14` §3.2 的抓包回归 `end ≈ 回合开始 + 时长` 相容；`TimerInf` 线上 `end=0` ⇒ `None` ⇒ 空白。）

| `client/src/screens/play_screen.gd::_online_tick` | `_turn_clock.advance(delta)` + `seconds_left()`（时长 − 已过 tick，墙钟折 tick） | `left = 剩余秒(end_of_turn_tick, 平面 tick)`；`end==0` ⇒ 空白 |
| `src/_scaffold/flow_clock_class.rs` | — | 新增纯函数 + `#[func]`：`seconds_until_turn_end(end_of_turn_tick, now_tick)`（`0` 哨兵 ⇒ `-1`），带单测 |
