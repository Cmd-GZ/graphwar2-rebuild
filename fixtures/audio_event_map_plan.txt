## 4. hook 点（全部**只读**：`Interceptor.attach`，onLeave 不改返回值、不写目标内存）

地址口径 = **ELF vaddr（RVA）**，下断 = `base + RVA`（Ghidra = RVA + `0x100000`）。
函数边界全部取自 `.eh_frame` FDE（`tools/replay_clock_disasm.py fde`）。

### 4.1 音频侧（真值：谁把哪个 stream 装到谁身上、谁 play）

| key | RVA | 身份 | 抓什么 |
|---|---|---|---|
| `load` | `0x4b1da0` | `ResourceLoader::load` 绑定（`&'static str` + 长度） | **路径字面量 + 长度**（`rdi`/`esi`）+ 返回值 `(rax,rdx)` = 载进来的资源句柄 ⇒ **资源名 ↔ 对象指针**的唯一来源 |
| `ctor` | `0x5238c0` | `SoundHandler` 构造收尾（`0x4bf550` 尾调用） | 入参 `rdi` = 载荷结构体（5 个 16 字节资源对，**载入序**）；返回 `rax` = 最终 handler 指针 ⇒ **资源槽偏移 ↔ 资源** |
| `eaud` | `0x4bed70` | `EffectAudioData::new`（6 个调用点唯一的收窄口） | `retaddr`（= 哪一条 match 臂，**静态已知**）+ `rsi/rdx`（16 字节候选一）+ `rcx/r8`（候选二）+ `r9d`（payload 值字段）+ `xmm0`（音量 dB） |
| `sstr` | `0x3ebb80` | `AudioStreamPlayer::set_stream` 绑定 A | `rdi`/`rsi` 及各自 16 字节窗口 |
| `sstr2` | `0x3eb8b0` | 同上绑定 B | 同上 |
| `play` | `0x8ae4c0` | **`AudioStreamPlayer::play`** | `rdi`（player 对象）+ `retaddr` + 当前 tick |
| `q` | `0x41d060` | 从 `self+slot` 取资源句柄的辅助 | `rdi`（= `self+slot`）+ `retaddr`（call site 决定 slot）+ `(rax,rdx)` |

### 4.2 事件侧（真值：哪个事件触发了哪一条臂）

| key | RVA | 身份 | 抓什么 |
|---|---|---|---|
| `eff` | `0x4bf090` | `effect_info_event` 处理函数（681 B） | `self`、payload 指针、`[payload]` tag、`[payload+0x1c]` u32、`[payload+0x20]` **u8 kind**、`retaddr` |
| `sold` | `0x4bf340` | `soldier_info_event`（188 B） | 同上（预期不校验 tag、kind 无意义） |
| `entrm` | `0x4bf480` | `entity_removed_event`（193 B） | 同上 |

| `w_eff`/`w_sold`/`w_gst`/`w_entrm` | `0x4bf400`/`0x4bf420`/`0x4bf440`/`0x4bf460` | 4 条订阅的 `dyn FnMut` 胶合 shim（每个 32 B，`lea` 出上面 4 个真函数） | `retaddr`（**= 谁派发了这条事件**，这是"触发源函数地址"的正面答案）+ `rsi` = payload |
| `proc` | `0x4bfe10` | `SoundHandler::process`（5052 B，每帧；`humm` 泵 + 队列 play） | 只计数 + 首次抓 `self`/`ev` 指针（60/s，不能逐次记） |
| `tick` | `0x519840` | `GraphwarTickHandler::tick`（60/s，`[rdi+0x40]` = tick 计数） | 只更新 `curTick`（**时间轴的真值**），不逐次记 |

**为什么 hook 这些而不是 hook 资源名**：音频资源在运行时是 `Ref<AudioStreamMP3>` 的
对象指针，字符串路径只在 `load` 那一刻以 `&'static str + len` 出现（`.rodata 0x1c2c1a`
起 5 条路径**首尾相接、无 NUL**，所以 `strings` 会骗人，必须按长度截断）。所以
"资源名"只能从 `load` 抓，"资源名 ↔ 槽"只能靠**对象指针相等**接起来。

## 5. 对齐方法（**序列号**为主轴，tick 为第二轴；**不用墙钟**）

回放播放有抖动（llvmpipe 软渲染，帧率不稳），所以**墙钟时间戳只做记录、不做对齐**。
两侧各自有严格单调的序号：

* **音频侧**：`play` 钩子的调用序号 `n_play = 1,2,3…`（同一进程内严格单调，
  且每个 `play` 前必然有一条 `eaud` 记录 ⇒ `n_eaud` 与 `n_play` 有固定配对关系）。
* **事件侧**：解压同一份回放得到的 JSONL 行号 `n_ev = 0,1,2…`（= 注入顺序，见
  `src/graphwar_replay_reader.rs`：逐行 `serde_json` → `Vec<EventInfo>`，**顺序即行序**）；
  同时每条事件自带 `tick`。

**两级对齐**：

1. **第一级（tick 轴，主判据）**：`play` 发生时读 `GraphwarTickHandler[+0x40]` 得 `t_play`。
   `EffectInfo` 带 `start_tick`，`FunctionActive` 带 `active_tick` ⇒ 事件侧能给出
   "这条音效应该在第几 tick 响"的**预测值**。判据：`|t_play - start_tick| <= 2` tick
   （= 2 帧）算命中；3..8 tick 算"迟"（必须解释）；> 8 tick 不算命中。
   * 也允许 `play` 发生在 `start_tick` **之后若干 tick**（队列 + 每帧预算），
     所以还要看 `play` 的**序号**是否与事件序一致。
2. **第二级（序列号轴，独立校验）**：把两侧的**事件类型序列**写出来，
   逐项比对单调性：
   `SoldierInfo×3 → EntityRemoved → (空窗) → Explosion → Spark → Explosion`。
   音效侧按 `n_play` 排出的槽序列必须与它同形（允许中间插空，不允许换位）。
   **两条轴都过才算"观测"；只有一条过算"推断"。**

**反例检查（必须做，不是可选）**：

* **撞车**：两条不同的事件（类型或 payload 值不同）是否落到同一个音频资源？
  （预期**会有**：`effect_type=2` 与 `=3` 都落 `spark` 槽，这是静态已知的"四臂落三槽"。）
* **孤儿**：有没有音频播放**对不上任何事件**？（预期：`pop`/`unpop` 在**载入回放**
  那一段（tick 5/6 的事件被批量注入）就该响，若观测到却"对上 5/6 之前"要先解释。）
* **沉默**：有没有事件**没响**？（负预测：`game_state_info_event`、`EntityEffectInfo`、
  `LifeInfo`、`PosInfo`、`FunctionInfo` 全部不该响。）
* **负对照（证明钩子有效）**：`load` 必须恰好 5 次 `res://sounds/*.mp3` + 1 次
  `res://sounds/humm.wav`（`FileAccess::get_file_as_bytes`，走 `0x3eaa00` 不是 `0x4b1da0`）。
  若 `load` 一次都没抓到，**先怀疑钩子没挂上**，不能直接下"没有音效"的结论。

## 8. 判据（一条映射行什么时候可以进 `fixtures/audio_event_map.tsv`）

一条映射要成立，**必须三件事同时为真**：

1. **资源**：该 `play` 前的 `eaud` 里，资源那一侧的 16 字节句柄 == `load` 抓到的
   `res://sounds/<name>.mp3` 的句柄（**指针相等**，不是名字像）；
2. **事件**：该 `eaud` 的 `retaddr` 落在**静态已知**的某条臂上（`0x4bf1aa`→`+0x80`、
   `0x4bf1f7`→`+0xa0`、`0x4bf244`→`+0x80`、`0x4bf28a`→`+0x90`、`0x4bf39e`→`+0xb0`、
   `0x4bf4e3`→`+0xc0`），且槽偏移与 (1) 的资源指针一致；
3. **时刻**：tick 与事件侧 `start_tick` 的差 ≤ 2，且序列号单调一致。

三条全过 = **观测**；只过 1+2 = **推断**（写明缺 tick 对齐）；只有 1 = **未知**。
`cargo test` / 自写断言**不算**任何一级证据。
