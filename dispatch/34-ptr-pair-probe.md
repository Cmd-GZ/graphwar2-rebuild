# 34 · `agent/ptr-pair-probe`：在运行时抓 `(ptr, n)` 的两处读数，判掉 407 批残差的方向

**优先级 P0。** 这是 `docs/06 §40.7` 给的入口，也是目前**唯一**还没被否证的假设。

## 0. 为什么是它

剩下的失败几乎全在「1 ulp + 越界停」这一支：

```
fire 轴失败 433 批：Y 189（爆炸点 y 末位差）＋ E1 127 ＋ X 91
```

已排除的（都带数，别重推）：

```
① 求值器          逐位一致（eval_differ = 0，1287/1287）
② 点数组填充       真机 frida：写进去的 y 与求值器返回**逐位相同**（4942/4943 等，miss 唯一是 i=0 炮口）
③ pos_y 来自网络   已证伪
④ hole_point 回代  试过：fire 608 → 601（丢 7 得 0），已回退
⑤ 常数 ±1..8 ulp   无收敛 k
⑥ 报文层           `pos` 与 `end_x` 读**同一对 (ptr,len)、同一个下标**
                  （x86 0x472814–0x47286b、arm64 fire_functions 0x4a7a24–0x4a7b3c）
⑦ Y 桶里 46 批 Normal：`eval(回放文本, 回放 pos_x)` 命中 **0/46** ⇒ **回放自己不自洽**
```

**剩下的假设**：每发有**两次 `calculate_function`**（`gw+3c30c7` 与 `gw+3e2d3b`），
两块不同缓冲、**点数相同**；报文读的那一对 `(ptr,len)` 到底指向哪一块，运行时没抓过。

## 1. 要做什么（一次抓取，回答三个问题）

用 frida 在真游戏里打一炮，在 **`execute_results` 的 `movdqu`**（x86 `0x472814–0x47286b` 那条）
处断下来，抓：

```
① rdx / rcx 的实际值（= 报文那次读的基址与下标）
② 与 `fire_functions` 那次 clone 出来的 (ptr, n) 对比：**是同一块缓冲吗？**
③ 若是两块：两块的**内容是否逐位相同**？若不同，差在哪几个点？
```

再补一条（便宜且关键）：

```
④ 统计"两次 calculate_function 返回的数组是否逐位相同"——在 N=20 发里各比一次
   ⇒ 若**总是相同**，"两条数组"这条假设就被否掉；若**有时不同**，那就是 1 ulp 的来源
```

## 3. 纪律（这几条决定结论可不可信）

- **原始样本必须入库**：抓到的 `(rdx, rcx, ptr, n)` 与两块数组的**摘要**（sha256 / 前若干点 hex）写进
  `fixtures/`，**只文本**，去路径用户名；
- **地址必须带构建**（`libgraphwarrust.so` sha256 `9a538115…`）；
- **负结论要有正对照**：说"两块相同"之前，先用一个已知不同的例子证明你的比对代码能报不同；
- 若抓不到（游戏跑不起来/断点不进）：**如实报"做不了 + 卡在哪"**，不许用静态推测代替。
