# `dispatch/replays/` —— **临时**样本，用完必须删

本目录只放**下游分析用**的 replay 样本。它们**永远不进 master**（`dispatch/` 每轮合并时整体剔除），
但仍然是二进制衍生内容（游戏运行时产物），**按 AGENTS 规矩不长期保存**。

## 规矩

1. **做完就把 `dispatch/replays/` 整个删掉**（`git rm -r dispatch/replays && rm -rf dispatch/replays`），
   并在你的交付分支里**不要**包含它们；
2. 需要留证据时，**只把关键数值以文本形式**写进 `docs/06`（坐标、bits、批号），不要留原文件；
3. 若必须再要一份，找协调方重新传。
