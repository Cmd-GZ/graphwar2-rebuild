## 1. 要做什么

1. **先固定一个"可复现的局面"**（这是全部工作的关键）：
   ```
   · 用固定关卡种子（`GW2_MATCH_SEED`，76 号已加的旋钮）
   · 固定窗口尺寸、固定 DPI、固定 Godot 版本（4.7.2）
   · 固定到某个 tick 停下（原版用 frida 控帧；我方用 GwReplayDriver 的 seek）
   ```
2. **两路截图**：
   ```
   原版：真机 + Xvfb（固定尺寸），frida 在目标 tick 触发 `Viewport.get_texture().get_image()` 或外部 X 截图
   我方：同一台机器、同一 Xvfb 尺寸，headless/Xvfb 截图
   ```
3. **对拍口径（三层，先粗后细）**：
   ```
   L1 尺寸与主色分布（粗筛，能被背景/缩放差异直接打红）
   L2 分区差异（把屏幕切成 6×4 块，报每块的平均色差；定位"差在哪个区域"）
   L3 逐像素（只在 L1/L2 都过时才做；报差异像素比例与最大通道差）
   ```
4. **首批样本 ≥3 屏**：主菜单、准备态（准备圈 + 号码）、对局中（棋盘 + 网格 + 士兵）。
5. **判据**：先给"能接受的门槛"（例如 L2 每块 ≤2/255），再跑；**不许先看结果再定门槛**。

## 2. 硬红线

```
① 门槛**先写死再跑**（预注册）；跑完不许改门槛来"让它过"
② 两路必须**同分辨率、同 DPI、同 Godot 版本**；不同就如实写"不可比"
③ 抓不到就报"卡在哪"（OS 级截图权限 / frida 能否在渲染线程取图），不许用"看起来差不多"代替
④ 截图**不入库**（大）；入库的只有"差异表 + 门槛 + 命令"；必要时放 `docs/img/` 一两张对照图
```
