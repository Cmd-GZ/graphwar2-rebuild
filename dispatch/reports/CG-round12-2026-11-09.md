## 3. 57：**73% 不是天花板**（本轮最大的正面结果）

51 号把结构指纹做到 72.7% 并断言"天花板 ≈73%，再调权重没用"。57 号换**新证据来源**，破了：

| 配置 | 留出半 top-1 / top-5 |
|---|---|
| (0) 51 号基线 | 72.73 / 88.48 |
| **基线 + `scal`=1（全部 IMM 立即数 xref）** | **78.18 / 89.09（+5.5）** |
| 基线 + `scal_c`（扣掉 Location 数字投影） | **78.18 / 89.09（同 ⇒ 非泄漏）** |
| 基线 + `shape`（机器码操作数形状） | 75.15（+2.5） |
| **基线 + `stok`（真字符串语义）** | **72.73（一格不动）** |
| 去掉 `gram` 只用 `shape` | 73.94（**shape 不能替代 `gram`**） |

**关键在泄漏控制**：正对照里 21.0% 的 `scal` 含自身 `Location` 的数字投影，目标集合只有 2.7%（差 7.8×）；
扣掉后**仍然是 78.2%** ⇒ 这 +5.5 点不是行号通道给的。
它还发现原有 `consts` **只收 `0x100..0xFFFFFFFF`**，把 `<0x100` 的关卡号/标志位/小计数**整段漏掉**了——这就是那 5.5 点的来源。

**结论**：73% 不是天花板，但 **78% 就到顶、80% 没过**；"真字符串内容语义"这条路**关闭**（第三次被否）。

**我独立复现**：重跑 `newev`（重建 v6 缓存 + 27 组消融全算）后 **`git status` 为空** ⇒ 生成的夹具与入库**逐字节相同**。

## 5. 把几条假设线关掉的四份（55 / 56 / 60 / 62）

- **55**：重叠假设**被否**（89 发 `cross` 0/178，检测器自测 79/79 抓到）。两个"大差"原来是：
  `0.37578125` = **166 个采样点**（不是"37.5 步"）、`0.000234375` = **`end_x` 早一个采样点**（不是"23.4 步"）。
  真因是**同批更早爆炸那几发已经挖了洞**——把它们的洞加进掩膜后，我方停点**逐位等于**回放；
  而按 `FunctionPoints` 顺序只有 61/63 ⇒ **报文顺序 ≠ 结算顺序**。
- **56**：打印-回代链**关掉**。链 6 环地址齐了（打印是 `{:.3}` **四舍五入半值取偶**，不是截断）；
  但 **167/280 批是 DiffEq，`corrected_function == function` 184/184 逐字节相同 ⇒ 链上根本没有常数**。
  unicorn 直调真二进制：**372/372 token、372/372 求值逐位相同**；±8 ulp 扫一遍仍算不出回放值。
  换成全精度常数**反而更差**（Y 26→1、X 52→0）⇒ 3 位小数这步是对的。
- **60**：`pos_y` 全 `.text` 只有两条写入指令，**一条 16 字节 `movdqu` 同时写 x 和 y**（`0x4729a0` / `0x472e14`），
  源分别是队列点数组 `pts[n-1]` 与点位表 ⇒ **结构上不可能只动 y**。unicorn 复现不出回放值；
  唯一能产出它的单 ulp 旋钮 = **修正常数 token「8.046」+1 ulp**（`y=e·c+8.046`，y 动 1、x 不动，与观测形状吻合，标**推断**）。
- **62**：全语料 1080 批。≥6 发**显著更差**（χ²=13.72, p=2.12e-4）但**不能当因果**（`shots` 是每局常量、
  9 个批只来自 4 份回放、混合局并起来 Fisher p=0.266）；**"大差只在多发"被推翻**——116 个大差批里 **86 个（74.1%）是单发批**，
  且幅度 >10 的 13 个**全在单发批**、**全是 `corrected_function` 含 NaN**。

## 6. 58：诚实负结论 + 一个结构性发现

角色标签正对照 **40.5%**，而**平凡基线 44.3%** ⇒ **推断器不如"永远猜最常见标签"**，所以明写"只当检索线索"。
但它顺手量出了调用图的结构：

```
直接 call rel32   34,374 条边
指针 call *slot   52,577 条边     ← 比直接边多 53%
取地址 lea [fn]    1,472 个函数被取
⇒ 2,045 个"直接调用者为 0"的函数只能靠指针边拿到调用者
```

这正是 `AGENTS.md` 那条纪律（"不要只看 `call rel32`"）的量化版。
