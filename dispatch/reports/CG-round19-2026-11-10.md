## 3. 93：顺序轴**也输了**，但输得比赢值钱

### 先看结论：预注册的 headline 是 1.16%

| 口径 | 留出准确率 | 备注 |
|---|---|---|
| **P0（预注册：无锚、band=256、gap=0.15）** | **4/344 = 1.16%** | **headline**，低于结构指纹 76.4% ⇒ 任务书的失败判据成立 |
| 预注册网格（选择只看 tune 171） | 19/173 = 10.98% | |
| 锚点分段（锚 tune 171 / 评估 holdout 173，互斥） | 82/173 = 47.40% | **半监督，必须标** |
| post-hoc 收敛带宽 band=1024 | 67/344 = 19.48% | 档 A 56/73 = 76.7% |

覆盖 12,736：A 2,887（22.7%）/ B 1,418 / C 2,424 / **无对齐 6,007（47.2%）**。
近孪生 27 行：**P0 = 0/27**；post-hoc 收敛带宽 21/27 = 77.8%（⚠ 同一留出人群子群 + post-hoc ⇒ **只能当新假设**）。

### ⭐ 真正值钱的是它量出的**结构上限**，而且不用对齐器就能算

```
344 对真值的秩对最长上升子序列 = 174/344 = 50.6%
  同 ISA（win↔linux）44.0% ｜ 同 OS 换版本（win_old↔win）24.7%
块内却高度一致：窗口 ±5 LIS 92.1% / ±10 88.8% / ±20 83.2% / ±50 74.3%；相邻对 di==dj 72.0%
偏移跨 −1,373 … +2,311
```

⇒ **两份构建的函数是"块内保序、块间置换"**（CGU 排布随 target / 版本变）
⇒ **"全局单调对齐"这条路的天花板就在 50%**，1.16% 与 19.48% 全在天花板下。

**它还抓到一个被过泛化的旧结论**：`tools/sym_match.py` 的"**79% 相邻对索引差相同**"是**块内性质**，
不能当全局用 —— **这正是 P0 失败的根因**（band 只给 ±256，而真值偏移高达 ±2,300）。

**我的独立复算**：我从真值表直接算 LIS —— 只能在 **242/344** 对上定位（arm64 秩我只用了已匹配子集）
⇒ `126/242 = 52.1%`；它 `174/344 = 50.6%`。**子集更小 ⇒ 我的比率略高，两者都指向天花板 ≈50%** ⇒ **headline 成立**。

**它给的下一步**：先**解块置换**（块级指纹不看顺序）再块内窄带 DP —— 锚点变体已把这条路天花板量成 **47.4%**。

## 6. 96：护栏最后一个洞补上了，而且它纠正了我

**真身**：`632 passed / 7 failed / 1 skipped`，断言 **639** vs 全量 **717** ⇒ **78 条没跑**。
⚠ **我算错的**：我之前写 `632+7+1=640` —— **skip 不是断言**，正确是 `717−(632+7)=78`。

**定因（观测，确定性可复现）：`user://` 不可写** ⇒ `_spawn_server()` 写不出日志 ⇒ 服务端 `LISTEN` 读不到
⇒ 两组"真服务端"各跑 2 条就 `return`（34 + 38 = 72）；另 **6 条**是 `if <文件打开成功>: <断言>` **没有 else**。

**它还发现 `docs/18` §10.3.3 的 `629/7` 从来不是一个真实读数**（是把两次运行拼成一行；`632 passed` 在任何日志里零命中）。

**修法**：组级进出 + **冻结表（33 组 = 717）** + **铁律「每条没跑的断言都要有 skip/FAIL 认领，否则记 FAIL、rc=1」**
+ `_degrade()` + 守卫块补 `else` 的显式 skip。

**我人为把 `user://` 弄成不可写验它的铁律**：

```
正常：    groups=33 checks=717 expected=717 missing=0  (claimed 0 / degraded 0 / silent 0) → 717/0/1
故障注入： groups=33 checks=639 expected=717 missing=78 (claimed 6 / degraded 72 / silent 0) → 632/7/9 + DEGRADED
```

**`silent 0` 是关键** —— 以前 78 条是**没人认领地消失**，现在每一条都有认领。

**它的一个提问，我的裁决**：`serve_match` 起不来时**保持红**，不改成绿色 skip ——
**我们自己的二进端起不来就是回归信号**，降级机制是给**环境前置**用的，不是给"我方构建坏了"用的。
