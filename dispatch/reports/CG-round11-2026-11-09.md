## 4. 52：矩阵放大 20 倍，并识别出两个**"oracle 在骗我们"**

7,106 条矩阵（16 种形状），16 进程 **250 s / 13.0× 聚合度**；受控测速 6.74×。
修前 157 条 token 串不一致（三组），**修了 3 条**（`src/math_function.rs`，每条都有 unicorn 复算）
⇒ 修后 **7106/7106** 一致、全量真语料 **16821/16821** 一致。

两个假象（方法论价值高于修 bug 本身）：
1. **`pow`**：上游 `emu.py` 用 python `a ** b`（定义域外给**正** NaN），而二进制是 `UND pow@GLIBC_2.2.5`
   ⇒ 换 ctypes 直调 libm 后 **205 个假不一致消失**（与 §30.3 的 `log(0)` 同类）；
2. **NaN 符号位**：剩 7 个槽只差符号位，闭环对照**真硬件** `_mm_add_sd/mul_sd`（dst 的 NaN 胜）
   vs **unicorn** 同一条指令（两次都返回 `+NaN`）⇒ 是 **QEMU softfloat 与真硬件不一致，我方 eval 是对的**，不修。

**我独立跑了三轴**（它改了求值器）：647 / 647 / 637 全部一致，一位没退。
